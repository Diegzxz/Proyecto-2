# Proyecto 2 - Calculadora

es una calculadora que hice en python, funciona en la consola

## como correrlo

necesitas tener python instalado, si no lo tienes lo puedes descargar de la pagina oficial de python

una vez que lo tengas abre la terminal, ve a la carpeta donde esta el archivo y escribe:

```
python "Proyecto 2.py"
```

## que hace

tiene un menu con varias opciones:

- operaciones basicas (suma, resta, multiplicacion, division, potencia)
- operaciones cientificas (factorial, raiz cuadrada, seno, coseno, exponencial, logaritmo natural)
- puedes evaluar funciones matematicas (lineal, cuadratica, cubica)
- grafica las funciones en la consola con asteriscos
- guarda un historial de todo lo que calculaste

solo escribes el numero de la opcion y le das enter, el programa te va pidiendo los datos
